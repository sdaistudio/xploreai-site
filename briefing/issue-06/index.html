01 · RESEARCH & DEVELOPMENT

AI learns from its own experience.

14 SEP

Google DeepMind's Dream-RSI explores recursive self-improvement

The research introduces an AI discovery agent that learns from its previous search trajectories and experiments with improved strategies offline — effectively "dreaming" about past attempts. Reports on the work indicate reductions of up to 162× in live search calls in some settings.

Why it matters: today's agents repeatedly spend compute rediscovering strategies. Systems that learn how to search and reason better from their own experience could make long-running research agents dramatically cheaper and more capable.

Read the coverage →
17 SEP

OpenAI publishes a formal framework for reporting model misalignment

The framework accompanies six reports of unexpected or concerning model behaviour and formalises how such incidents should be tracked, investigated and disclosed.

The shift in AI safety: benchmark safety → production monitoring → incident reporting.

Read the framework →
THIS WEEK

Anthropic measures real-world agent autonomy

Analysing millions of human-agent interactions, Anthropic found agent work sessions are getting longer — and software engineering accounts for nearly half of tool use in the analysed data.

The research signal: model intelligence + experience + self-improvement + long-running autonomy + monitoring.

02 · MODELS & TOOLS

Voice gets agentic, agents get trusted.

15 SEP · GOOGLE

Gemini 3.8 Live + Live Extended Thinking

Two new native conversational models: 3.8 Live, optimised for scalable, low-latency voice agents with visual grounding, and 3.8 Live Extended Thinking, which adds stronger multi-step reasoning for complex voice-driven work.

The real shift: from "voice → transcription → LLM → answer" to "voice → reasoning → tools → actions → natural spoken interaction" — significant for customer service, sales, healthcare assistance and personal AI companions.

Read Google’s announcement →
THIS WEEK · OPENAI

Astra goes deeper into real enterprise systems

OpenAI disclosed that Perplexity is using GPT-6 Astra for end-to-end systems work — writing communications, changing software and monitoring production systems — with substantially less human supervision. Separately, Hex uses Astra inside data agents to turn complex analysis into interactive visual reports.

More interesting than another benchmark: agent capability is starting to be measured by how rarely a human needs to intervene.

THIS WEEK · ANTHROPIC

Life Sciences Verification program

Qualified life-sciences researchers get more permissive access to advanced AI capabilities while additional safeguards stay in place.

An access architecture we may see much more often: general user → standard capabilities · verified professional → specialist capabilities · highly sensitive capability → controlled access + monitoring.
