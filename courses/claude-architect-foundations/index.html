FREE STUDY COURSE · CCAR-F · 5 MODULES · 30 TASK STATEMENTS

Claude Certified Architect – Foundations.

A study course for Anthropic's Claude Certified Architect – Foundations exam, built on its official guide: one module per domain and one session per task statement. The exam is scenario-based and practical (agent loops, subagents, hooks, tools, MCP, Claude Code configuration, structured output, context and escalation), so every session pairs an animated architecture with Python that really runs and scenario-style practice questions.

The exam

At a glance.

60questions
4 of 6scenarios per exam
720pass mark, on a 100–1,000 scale
$125exam fee (USD)

120 minutes of multiple-choice and multiple-response questions, proctored online or at a Pearson VUE centre, grouped under realistic production scenarios. It's for solution architects who build production applications with the Claude Agent SDK, Claude Code and MCP, with about six months of hands-on experience. The credential lasts 12 months.

The scenarios

Four of these six, at random.

Every question sits inside one of these production scenarios. The course's examples are built around them.

1. Customer support resolution agentAn Agent SDK agent with MCP tools for customers, orders, refunds and escalation, aiming for 80%+ first-contact resolution. Domains 1, 2, 5.
2. Code generation with Claude CodeSlash commands, CLAUDE.md configuration, and knowing when to use plan mode. Domains 3, 5.
3. Multi-agent research systemA coordinator delegating to search, analysis, synthesis and report subagents that produce cited reports. Domains 1, 2, 5.
4. Developer productivity with ClaudeAn agent that explores unfamiliar codebases with the built-in tools and MCP servers. Domains 2, 3, 1.
5. Claude Code for continuous integrationAutomated reviews, test generation and PR feedback with few false positives. Domains 3, 4.
6. Structured data extractionExtracting from unstructured documents, validating with JSON schemas, handling edge cases. Domains 4, 5.
