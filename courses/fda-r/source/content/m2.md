## 2.1 | Descriptive statistics I: centre and spread

Before modelling a series, describe it. Statisticians summarise a distribution with four **moments**:

| Moment | Question | Measures |
|---|---|---|
| 1st: central tendency | What is a typical value? | Mean, median, mode |
| 2nd: dispersion | How spread out is it? | Range, IQR, variance, SD |
| 3rd: skewness | Is it symmetric? | Skewness |
| 4th: kurtosis | How fat are the tails? | Kurtosis |

### Central tendency

- **Mean** = Σx / n: the arithmetic average. Use it for interval and ratio data.
- **Median**: the middle value of the sorted data, at position (n+1)/2. It isn't dragged around by outliers.
- **Mode**: the most frequent value. It's the only valid average for nominal data.

R has `mean()` and `median()` built in, but no function for the statistical mode, so write a one-line one:

```r
x <- c(10, 11, 12, 8, 9)
mean(x)
median(x)          # sorted: 8 9 10 11 12, so the middle value is 10

y <- c(20, 30, 25, 30, 40, 30, 35)
mode_stat <- function(v) { t <- table(v); as.numeric(names(t)[which.max(t)]) }
mode_stat(y)
```

### Dispersion

- **Range** = max − min. It's simple, but uses only two points.
- **IQR** = Q3 − Q1 is the spread of the middle 50%, and it's also the basis of the outlier rule from Module 1.
- **Quartile deviation** = (Q3 − Q1) / 2.

```r
z <- c(4, 9, 2, 6, 1, 12, 3, 8, 9)
range(z)
diff(range(z))                    # 12 - 1 = 11
quantile(z, c(0.25, 0.5, 0.75))
IQR(z)
IQR(z) / 2                        # quartile deviation
```

## 2.2 | Descriptive statistics II: risk, skewness and kurtosis

### Variance and standard deviation

Deviations from the mean always sum to zero, so we either take absolute values (mean absolute deviation) or square them (variance). The **standard deviation** is the square root of the variance. It's back in the original units, which is why finance calls it **risk** or **volatility**.

```r
r <- c(0.04, -0.01, 0.06, 0.02, -0.03, 0.05, 0.01)   # seven monthly returns
sum(r - mean(r))                  # always (almost) exactly zero
mean(abs(r - mean(r)))            # mean absolute deviation
var(r)
sd(r)
```

> [warn] R's `var()` and `sd()` divide by **n − 1** (the sample formula), not by n. With hundreds of daily returns the difference is negligible.

### The empirical rule

If returns are roughly normal, about **68%** fall within mean ± 1 SD, **95%** within ± 2 SD and **99.7%** within ± 3 SD. A stock with a mean return of 10% and an SD of 4% will usually return between 6% and 14%, and almost always between 2% and 18%.

### Coefficient of variation: risk per unit of return

CV = SD / mean. A smaller CV means you get return more consistently for the risk you take.

```r
stocks <- data.frame(stock = c("A", "B"), mean_ret = c(10, 12), sd_ret = c(6, 7))
stocks$CV <- round(stocks$sd_ret / stocks$mean_ret, 3)
stocks
```

> [read] Stock B has the higher risk (7% vs 6%), but its CV is lower (0.583 vs 0.600), so it pays more return per unit of risk.

### Skewness and kurtosis

| Measure | Value | Meaning for returns |
|---|---|---|
| Skewness = 0 | Symmetric | Gains and losses mirror each other |
| Skewness > 0 | Long right tail | Occasional big gains |
| Skewness < 0 | Long left tail | Occasional big losses (typical of stocks) |
| Kurtosis = 3 (excess 0) | Mesokurtic | Normal tails |
| Kurtosis > 3 (excess > 0) | Leptokurtic | Sharp peak, **fat tails**, more extreme days |
| Kurtosis < 3 (excess < 0) | Platykurtic | Flat, thin tails |

> [warn] Packages disagree on which kurtosis they report. `psych::describe()` reports **excess** kurtosis (compare with 0), while `moments::kurtosis()` reports **raw** kurtosis (compare with 3).

## 2.3 | Descriptive statistics in R: Bitcoin spot vs futures

Now on real data: daily Bitcoin **spot** prices against **CME Bitcoin futures** since futures trading began in December 2017. The returns are daily log returns.

```r
url <- "https://xploreai.co.in/courses/fda-r/data/"
bitcoin <- read.csv(paste0(url, "bitcoin.csv"))
str(bitcoin)
```

```r
mean(bitcoin$Spot_Returns)
sd(bitcoin$Spot_Returns)
range(bitcoin$Spot_Returns)
summary(bitcoin[, -1])     # -1 drops the Date column
```

`summary()` gives no SD, skewness or kurtosis. The `psych` package's `describe()` gives all of them at once:

```r eval=false
install.packages("psych")
```

```r
library(psych)
describe(bitcoin[, -1])
```

> [read] Mean daily returns are tiny (about 0.075%, so `describe()` rounds them to 0), but the **SD is about 4% a day**, which is very risky. **Skew** is negative for both return series, so crashes are bigger than rallies. **Kurtosis** (excess) is 11.2 for spot and 4.8 for futures, both far above 0, so the tails are fat: extreme days happen far more often than a normal distribution would predict. The `mad`, `trimmed` and `se` columns are the median absolute deviation, the 10% trimmed mean and the standard error.

The numbers tell you the shape. Charts show it.

```r

hist(bitcoin$Spot_Returns, breaks = 80, col = rust, border = "white",
     xlab = "Daily log return", ylab = "Number of days",
     main = "Bitcoin spot returns: tall peak, long tails")
```

### Four charts at once with par(mfrow)

```r h=6
par(mfrow = c(2, 2))
hist(bitcoin$Spot_Returns,   breaks = 60, col = rust,     border = "white", main = "Spot returns",   xlab = "")
hist(bitcoin$Future_Returns, breaks = 60, col = espresso, border = "white", main = "Futures returns", xlab = "")
hist(bitcoin$Spot_Price,     breaks = 40, col = peach,    border = "white", main = "Spot price",     xlab = "")
hist(bitcoin$Future_Price,   breaks = 40, col = "#C9B8A3", border = "white", main = "Futures price",  xlab = "")
par(mfrow = c(1, 1))   # always reset afterwards
```

### Box plots: outliers at a glance

```r h=5
par(mfrow = c(1, 2))
boxplot(bitcoin$Spot_Returns,   main = "Spot returns",    col = peach, border = espresso, outcol = rust)
boxplot(bitcoin$Future_Returns, main = "Futures returns", col = peach, border = espresso, outcol = rust)
par(mfrow = c(1, 1))
```

> [read] Every dot is a day outside the 1.5 × IQR fences. There are dozens on **both** sides, which fits the high kurtosis from `describe()`.

### Scatter plot: do spot and futures move together?

```r
plot(bitcoin$Spot_Returns, bitcoin$Future_Returns, pch = 16, cex = .5,
     col = adjustcolor(rust, .45), xlab = "Spot return", ylab = "Futures return",
     main = "Spot vs futures daily returns")
abline(lm(Future_Returns ~ Spot_Returns, data = bitcoin), col = espresso, lwd = 2)
```

### Everything in one picture: pairs.panels()

```r h=6.5
pairs.panels(bitcoin[, -1], hist.col = rust, col = espresso, lm = TRUE, stars = TRUE)
```

> [read] The **diagonal** shows each variable's histogram, the **lower triangle** the scatter plots and the **upper triangle** the correlations. Spot and futures prices correlate at about 1.00 and their returns at about 0.9. Returns barely correlate with price levels. Pie and bar charts suit categorical data, so you'll rarely use them on prices.

## 2.5 | Time-series components and stationarity

A time series is observed at equally spaced, ordered points in time. It usually mixes four components:

| Component | What it looks like | Example |
|---|---|---|
| Trend | Long-run rise or fall | NIFTY since 2015 |
| Seasonality | A pattern that repeats every year | Car sales peaking at Diwali |
| Cycle | Multi-year boom and bust | Post-2008 recovery, the COVID crash |
| Noise | Random, unpredictable shocks | Surprise news |

These components make each observation depend on the one before, so the series is **non-stationary**.

> [concept] **A stationary series has a constant mean and a constant variance over time.** Regress one non-stationary series on another and you can get a high R² for a relationship that doesn't exist. This is called a **spurious regression**. The classic story is a trader whose daily P&L appears to be "explained" by where a fly sits on the wall. Time-series models need stationary data.

The usual fixes are a first difference (Δyₜ = yₜ − yₜ₋₁), a second difference, or a log difference (which gives log returns). The usual tests are:

| Test | H₀ (null) | Stationary if… |
|---|---|---|
| ADF (Augmented Dickey-Fuller) | Unit root, so non-stationary | p < 0.05, or the test statistic is below the critical value |
| PP (Phillips-Perron) | Unit root, so non-stationary | p < 0.05 |
| KPSS | **Stationary** | p > 0.05 (the logic is reversed) |

> [warn] Never decide from a chart alone. A series can look flat and still fail the test. Plot it, then test it.

## 2.6 | Testing stationarity in R

The classic airline passengers series (monthly, 1949–1960) has both a trend and seasonality.

### Step 1: declare it as a time series

A data frame isn't a time series. `ts()` tells R the start date and the **frequency**, meaning the number of observations per year: 12 for monthly data, 4 for quarterly, 1 for annual, about 252 for daily trading days.

```r
AP <- read.csv(paste0(url, "AirPassengers.csv"))
str(AP)
AP_T <- ts(AP$Passengers, frequency = 12, start = c(1949, 1))
str(AP_T)
```

```r
plot(AP_T, col = rust, lwd = 2, ylab = "Passengers ('000)", xlab = "",
     main = "Airline passengers: trend + seasonality")
```

### Step 2: the ADF test with urca

```r eval=false
install.packages("urca")
```

```r
library(urca)
model1 <- ur.df(AP_T, type = "none", lags = 1)
summary(model1)
```

> [read] Compare the **test statistic** (the `Value of test-statistic` line) with the **5pct critical value**, which is −1.95 here. The statistic is *above* the critical value (less negative), so we **fail to reject H₀**. The series has a unit root and is **non-stationary**.

### Step 3: difference and test again

```r
AP_T_D <- diff(AP_T, differences = 1)
head(AP_T_D)             # 118-112 = 6, 132-118 = 14, ...
plot(AP_T_D, col = rust, lwd = 1.6, ylab = "Change", xlab = "",
     main = "First difference: the trend is gone")
abline(h = 0, col = espresso, lty = 2)
model2 <- ur.df(AP_T_D, type = "none", lags = 1)
summary(model2)@teststat
model2@cval
```

> [read] The statistic is now far below −1.95, so we **reject H₀**: the differenced series is **stationary**, and passengers are **I(1)** (integrated of order 1). The workflow is always **declare → plot → test → difference → re-test → model**.

### Getting a p-value instead

`tseries` gives the same tests as p-values, which are often easier to read:

```r
library(tseries)
adf.test(AP_T_D)
kpss.test(AP_T_D)
```

> [tip] Notice the differenced chart still fans out over time: its variance is growing. Taking `diff(log(AP_T))` fixes that too, which is why finance works with **log returns** rather than raw price changes.
