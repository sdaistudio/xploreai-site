Before you start

Set up in ten minutes.

Install R first, then RStudio Desktop. Then paste this into the RStudio console once to install every package the course uses:

R
install.packages(c("dplyr", "tidyr", "stringr", "ggplot2", "psych", "urca", "tseries",
                   "car", "lmtest", "forecast", "vars", "dLagM", "xts", "quantmod",
                   "rugarch", "FinTS", "TTR", "caret", "rpart", "randomForest",
                   "e1071", "neuralnet"))

Every script reads its data straight from this site, so there are no file paths to fix. Each module page also has a Download the R script button with all of that module's code in one file.
