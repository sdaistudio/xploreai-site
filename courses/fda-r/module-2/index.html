Session 2.1

Descriptive statistics I: centre and spread

Before modelling a series, describe it. Statisticians summarise a distribution with four moments:

MomentQuestionMeasures
1st: central tendencyWhat is a typical value?Mean, median, mode
2nd: dispersionHow spread out is it?Range, IQR, variance, SD
3rd: skewnessIs it symmetric?Skewness
4th: kurtosisHow fat are the tails?Kurtosis

Central tendency

  • Mean = Σx / n: the arithmetic average. Use it for interval and ratio data.
  • Median: the middle value of the sorted data, at position (n+1)/2. It isn't dragged around by outliers.
  • Mode: the most frequent value. It's the only valid average for nominal data.

R has mean() and median() built in, but no function for the statistical mode, so write a one-line one:

R
x <- c(10, 11, 12, 8, 9)
mean(x)
median(x)          # sorted: 8 9 10 11 12, so the middle value is 10

y <- c(20, 30, 25, 30, 40, 30, 35)
mode_stat <- function(v) { t <- table(v); as.numeric(names(t)[which.max(t)]) }
mode_stat(y)
Console output
[1] 10
[1] 10
[1] 30

Dispersion

  • Range = max − min. It's simple, but uses only two points.
  • IQR = Q3 − Q1 is the spread of the middle 50%, and it's also the basis of the outlier rule from Module 1.
  • Quartile deviation = (Q3 − Q1) / 2.
R
z <- c(4, 9, 2, 6, 1, 12, 3, 8, 9)
range(z)
diff(range(z))                    # 12 - 1 = 11
quantile(z, c(0.25, 0.5, 0.75))
IQR(z)
IQR(z) / 2                        # quartile deviation
Console output
[1]  1 12
[1] 11
25% 50% 75% 
  3   6   9 
[1] 6
[1] 3

Session 2.2

Descriptive statistics II: risk, skewness and kurtosis

Variance and standard deviation

Deviations from the mean always sum to zero, so we either take absolute values (mean absolute deviation) or square them (variance). The standard deviation is the square root of the variance. It's back in the original units, which is why finance calls it risk or volatility.

R
r <- c(0.04, -0.01, 0.06, 0.02, -0.03, 0.05, 0.01)   # seven monthly returns
sum(r - mean(r))                  # always (almost) exactly zero
mean(abs(r - mean(r)))            # mean absolute deviation
var(r)
sd(r)
Console output
[1] -5.2042e-18
[1] 0.025714
[1] 0.0010667
[1] 0.03266
Watch out

R's var() and sd() divide by n − 1 (the sample formula), not by n. With hundreds of daily returns the difference is negligible.

The empirical rule

If returns are roughly normal, about 68% fall within mean ± 1 SD, 95% within ± 2 SD and 99.7% within ± 3 SD. A stock with a mean return of 10% and an SD of 4% will usually return between 6% and 14%, and almost always between 2% and 18%.

Coefficient of variation: risk per unit of return

CV = SD / mean. A smaller CV means you get return more consistently for the risk you take.

R
stocks <- data.frame(stock = c("A", "B"), mean_ret = c(10, 12), sd_ret = c(6, 7))
stocks$CV <- round(stocks$sd_ret / stocks$mean_ret, 3)
stocks
Console output
  stock mean_ret sd_ret    CV
1     A       10      6 0.600
2     B       12      7 0.583
How to read it

Stock B has the higher risk (7% vs 6%), but its CV is lower (0.583 vs 0.600), so it pays more return per unit of risk.

Skewness and kurtosis

MeasureValueMeaning for returns
Skewness = 0SymmetricGains and losses mirror each other
Skewness > 0Long right tailOccasional big gains
Skewness < 0Long left tailOccasional big losses (typical of stocks)
Kurtosis = 3 (excess 0)MesokurticNormal tails
Kurtosis > 3 (excess > 0)LeptokurticSharp peak, fat tails, more extreme days
Kurtosis < 3 (excess < 0)PlatykurticFlat, thin tails
Watch out

Packages disagree on which kurtosis they report. psych::describe() reports excess kurtosis (compare with 0), while moments::kurtosis() reports raw kurtosis (compare with 3).

Graphical analysis: histograms, box plots and scatter plots

The numbers tell you the shape. Charts show it.

Histogram: the shape of the distribution

Session 2.5

Time-series components and stationarity

A time series is observed at equally spaced, ordered points in time. It usually mixes four components:

ComponentWhat it looks likeExample
TrendLong-run rise or fallNIFTY since 2015
SeasonalityA pattern that repeats every yearCar sales peaking at Diwali
CycleMulti-year boom and bustPost-2008 recovery, the COVID crash
NoiseRandom, unpredictable shocksSurprise news

These components make each observation depend on the one before, so the series is non-stationary.

The idea

A stationary series has a constant mean and a constant variance over time. Regress one non-stationary series on another and you can get a high R² for a relationship that doesn't exist. This is called a spurious regression. The classic story is a trader whose daily P&L appears to be "explained" by where a fly sits on the wall. Time-series models need stationary data.

The usual fixes are a first difference (Δyₜ = yₜ − yₜ₋₁), a second difference, or a log difference (which gives log returns). The usual tests are:

TestH₀ (null)Stationary if…
ADF (Augmented Dickey-Fuller)Unit root, so non-stationaryp < 0.05, or the test statistic is below the critical value
PP (Phillips-Perron)Unit root, so non-stationaryp < 0.05
KPSSStationaryp > 0.05 (the logic is reversed)
Watch out

Never decide from a chart alone. A series can look flat and still fail the test. Plot it, then test it.

Session 2.6

Testing stationarity in R

The classic airline passengers series (monthly, 1949–1960) has both a trend and seasonality.

Step 1: declare it as a time series

A data frame isn't a time series. ts() tells R the start date and the frequency, meaning the number of observations per year: 12 for monthly data, 4 for quarterly, 1 for annual, about 252 for daily trading days.

R
AP <- read.csv(paste0(url, "AirPassengers.csv"))
str(AP)
AP_T <- ts(AP$Passengers, frequency = 12, start = c(1949, 1))
str(AP_T)

Compare the test statistic (the Value of test-statistic line) with the 5pct critical value, which is −1.95 here. The statistic is above the critical value (less negative), so we fail to reject H₀. The series has a unit root and is non-stationary.

Step 3: difference and test again

R
AP_T_D <- diff(AP_T, differences = 1)
head(AP_T_D)             # 118-112 = 6, 132-118 = 14, ...
plot(AP_T_D, col = rust, lwd = 1.6, ylab = "Change", xlab = "",
     main = "First difference: the trend is gone")
abline(h = 0, col = espresso, lty = 2)
model2 <- ur.df(AP_T_D, type = "none", lags = 1)
summary(model2)@teststat
model2@cval

How to read it

The statistic is now far below −1.95, so we reject H₀: the differenced series is stationary, and passengers are I(1) (integrated of order 1). The workflow is always declare → plot → test → difference → re-test → model.

Getting a p-value instead

tseries gives the same tests as p-values, which are often easier to read:
