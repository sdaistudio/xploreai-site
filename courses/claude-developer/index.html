STUDY COURSE · CCDV-F · 8 MODULES · 44 SESSIONS

Claude Certified Developer – Foundations.

A study course for Anthropic's Claude Certified Developer – Foundations exam, built on its official blueprint: one module per exam domain. Every idea is shown as an animated diagram, a screen or a config file, then built step by step in Python that really runs, with its real output, and checked with practice questions.

Start with Module 1 → The exam at a glance

Unofficial. Not affiliated with or endorsed by Anthropic. Exam facts are taken from Anthropic's public Exam Guide, version 1.0 (July 2026); check it for the latest. Practice questions here are our own and are not drawn from the exam. API details move fast: confirm them in Anthropic's documentation before you ship.

The exam

At a glance.

53questions
120minutes
720pass mark, on a 100–1,000 scale
$125exam fee (USD)

Multiple-choice and multiple-response questions (each says how many answers to pick), proctored online or at a Pearson VUE centre. It's for hands-on developers who build, integrate and ship Claude-powered apps, agents and workflows; Anthropic suggests one to five years of software engineering, six months with Claude or a similar LLM, and Python or TypeScript. The credential lasts 12 months, with free online renewal.

How each session works

See it, build it, check it.

Across the course: 38 animated diagrams, screens and comparisons, 77 Python cells with their real output, 35 config files and API snippets, and 92 practice questions.

DiagramsAnimated sequence diagrams and workflows: who calls whom, in what order.
Python that runsPlain Python 3, run when the page was built. The output you see is what it printed. Where Claude would answer, a scripted stand-in plays its part, and says so.

Config filesCLAUDE.md, settings.json, tool schemas and shell commands, as you would write them.
